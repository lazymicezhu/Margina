# Changelog

## 0.1.0 — 2026-10-22

Initial local preview, named **Margina**.

- Mobile-first library, bilingual PDF / paragraph views and glossary.
- Local notes, PDF highlights, bookmarks, reading progress and Markdown export controls.
- Adapter for existing academic-pdf-bilingual / BabelDOC jobs.
- English and Simplified Chinese READMEs, architecture, contribution, security and roadmap documents.
- Build-only continuous integration; private documents and generated output excluded from Git.
- Retained legacy database and reading-bundle identifiers to preserve existing preview data.

Cloud synchronization, accounts, offline app installation and hosted deployment are not included.
