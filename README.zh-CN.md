# Margina

**Read. Reflect. Connect. · 阅读、思考、连接。**

[English](README.md) | 简体中文

优先适配手机网页的双语学术文献阅读器，将高亮、笔记和阅读进度保存在浏览器中。Margina 复用 `academic-pdf-bilingual` / BabelDOC 工作流的最终 PDF、翻译片段和术语表，本身不翻译文献，不需要 AI API 密钥。

> **v0.1.0。** 已实现公共书库、账号同步及管理后台，可按 [部署步骤](docs/CLOUDFLARE.md) 直接发布到 Cloudflare Workers / D1 / R2，无需先启动本地预览或推送 Git。[公共网站](https://margina.lazymicezhu.com) 已部署，D1 和私有 R2 已连接；邮箱验证码登录与管理后台已启用。

## 功能

- 我的笔记按书籍归类，默认收起，最近编辑的书籍排在前面；展开后按页码浏览，可跳到原文对应页、复制或单独导出本书笔记。书库、书架与我的上传中，有笔记的封面右侧靠上显示红色标签和个人笔记条数；无笔记不显示，锁定文献和其他账号的笔记不会泄露。

- 打开文献会记录浏览器历史。浏览器返回与阅读器内的返回按钮均恢复原列表、文件夹、搜索条件和滚动位置；前进可重新打开文献，并重新检查当前账号及文件夹权限。刷新页面回到书库，不恢复仅存于内存的阅读页面。

- 书架书籍信息每批最多加载 40 本，同时最多处理两批；已加载的书名按账号缓存，文件夹权限确认后优先显示。加载中的文献显示等待状态，连接失败可重试，不再误标为已撤下；仅服务器确认不可访问时显示不可用提示。

- 邮箱验证后注册并设置密码，之后用邮箱和密码登录，登录状态保留 30 天；忘记密码可通过邮箱验证重设。旧邮箱沿用原账号、书架和笔记。注册和找回密码仍通过 Cloudflare Access 验证，免费方案的用户数量限制仍适用。

- 网站默认进入我的书架。可创建文件夹、设置密码，并通过书籍卡片的编辑按钮归类。书名备注会替代书架和阅读页的原书名，清空后恢复；原文件名和公共书库标题不变。
- 文件夹和备注随账号同步。刷新页面后密码文件夹重新锁定，个人笔记、私密文件和书架修改入口均校验锁定状态；公开书库中的原文件仍公开。删除已解锁的文件夹会把书籍移回书架首页。

- 游客可浏览、搜索和阅读公共书库；登录后可上传 PDF、TXT 及 PDF 配套阅读包，选择「仅自己可见」（默认）或「公开到书库」，上传后加入个人书架。
- 书库支持公开文件夹，登录后可新建；上传时可选择已有文件夹或新建并选中。公开文献归入书库文件夹，私密文献归入个人书架文件夹。创建者及管理员可改名或删除公开文件夹，删除后文献移回书库首页；上传者可在「书库」和「我的上传」的文献卡片上点击「归类」；管理员可在后台对全库公开文献（含已撤下文献）归类，并查看当前位置。两个入口均支持选择已有文件夹、新建并选中、移回书库首页；私密文献仍在上传者的个人书架中归类。书库首页搜索覆盖所有文件夹，文件夹内搜索仅查当前文件夹。重复公开文献和阅读包保留对应 PDF 的原位置。归类需要联网，私密上传会先同步阅读记录再归类；失败会提示并保留重试入口。
- 书架支持账号同步的五星评分，每个文件夹内高星级优先、同星级按最近阅读排序；评分收为右侧的一颗星，点击后原位展开五颗星，选完自动收回；再次点击当前星级可取消评分。编辑与移出书架图标并排放在右侧，移出按钮不再显示文字。PDF 上传时另存 JPEG 封面，阅读包可内嵌最终 PDF 的中文首页缩略图；卡片直接加载小图，无需解析 PDF。旧书由上传者或管理员首次查看时补生成一次，普通读者不会为封面下载 PDF；私密封面保留账号与文件夹权限。TXT 或加载失败时保留文字封面。隐藏重复文件名及 PDF 类型标签；后台删除完成后从文献管理及上传列表消失，删除未完成的条目仍可重试。
- 账号之间的笔记、高亮、书签和阅读进度相互独立；支持本机持久化队列、版本检查、冲突副本、删除同步和失败重试。取消收藏保留个人笔记，也不删除公共文件。
- 设置已移除本机文献导入、游客记录合并及上传管理快捷按钮；「我的上传」仍保留在桌面和手机导航中。已有浏览器数据继续保留。

- TXT 支持 UTF-8、带 BOM 的 UTF-16、GB18030，单份不超过 10 MB；支持字号调整、固定分页、左右滑动、摘录、笔记与进度同步，内容按纯文本显示；手机正文两端对齐、左右各留 16px，段尾及原有强制换行保留自然排版。
- 导入 PDF，按 SHA-256 去重，搜索文献库、收藏文献。
- TXT、PDF 与段落阅读可选择「连续下滑」或「左右翻页」，浏览器记住选择。连续阅读仅渲染附近页面，按当前可见页记录进度；翻页按钮和页码跳转定位到页首，保留选词与缩放。
- 使用兼容 Safari 的 PDF 引擎；阅读前校验公共 PDF 缓存，无法读取或校验不一致时重新下载，并保留笔记和进度。校验后的数据直接用于阅读，不再二次读取缓存；公共文献信息未变化时不重写 PDF 缓存。加载失败时可点击「重新加载」。
- 在双语 PDF 的中文半页、英文半页和整页对照之间切换。原版 PDF 按屏幕像素密度绘制，双指缩放后补绘清晰版本，并限制画布内存占用；低分辨率扫描件仍受原文件清晰度限制。
- 默认打开原版 PDF，双语文献默认显示中文半页，有配套阅读包时也保持此默认。可手动切换到适合手机的段落阅读、逐段对照和原术语表。
- 「左右翻页」模式下，电脑鼠标点击纸张左侧空白处上一页、右侧空白处下一页，只有可翻页的两侧空白区域显示小箭头光标，纸张内保留正常选字且不点击翻页；划选、双击选词、控件操作和放大后的 PDF 拖动保留原有行为。
- 选中文字后，工具框显示在选区旁，随划选和滚动更新位置，限制在可见阅读区内，选区移出视野后隐藏。点击颜色直接保存高亮，也可选择记笔记；TXT 与段落正文不显示逐段记笔记按钮，保留已有笔记、书签和阅读进度。
- 精简文案、无边框明度分层，随系统切换浅色/暗色；说明可展开，笔记支持复制，对勾在 2.5 秒后淡出，并尊重减少动态效果设置。PDF 保留原稿颜色。
- 提供 Markdown 笔记下载入口；浏览器实际下载的端到端验证仍待完成。

段落模式使用翻译中间片段，可能不包含重复内容或后期排版修复；图表、公式、脚注与修订请以最终 PDF 为准。扫描 PDF 可以显示，但不会自动获得可选文字或 OCR。

## 部署到 Cloudflare

按 [完整步骤](docs/CLOUDFLARE.md) 创建 D1 / R2、配置邮箱登录和 `ADMIN_EMAILS`。管理后台入口为 `/admin`，支持按账号查看笔记，以及上传、撤下、恢复和删除文献。独立封面功能上线前须执行 `server/migrations/0005-paper-covers.sql`（或当前幂等的 `server/schema.sql`），不改写文献与阅读记录。正式资源绑定及非密钥设置保存在已纳入 Git 的 `wrangler.jsonc`，运行密钥保留在 Cloudflare。现有 Worker 已于 2026-10-27 通过 Workers Builds 连接本仓库，推送 `main` 自动触发发布：构建命令为 `npm test && npm run build:cloud`，部署命令为 `npx wrangler deploy --config wrangler.jsonc`。GitHub Actions 独立检查构建；明确需要手动发布时仍可使用 `npm run deploy:cloud`。

已有部署在发布书库文件夹功能前，需应用 `server/migrations/0004-catalog-folders.sql`，或重新执行当前 `server/schema.sql`。两者只添加表，不改写已有文献及阅读记录；仅修改本地源码不会更新线上网站。

## 本地开发

需要 **Node.js 22.13+** 和 npm。`.nvmrc` 使用 Node 22，请安装该系列的当前补丁版本。

```sh
git clone https://github.com/lazymicezhu/Margina.git
cd Margina
npm ci
npm run build:cloud
npm run dev:cloud
```

本地路径包含冒号时（例如 macOS 上的部分 iCloud 文件夹），开发服务器会自动使用临时路径别名；项目文件仍保存在原文件夹中。

打开[本地书库预览](http://127.0.0.1:8787/)，点击登录并选择测试账号 A 或 B，体验上传与个人书架。服务数据保存在忽略的 `.wrangler/` 目录；测试身份只在本机回环地址启用，不是真实云端账号。修改前端后重新运行 `npm run build:cloud`。详见 [Cloudflare 实现与配置](docs/CLOUDFLARE.md)。

`npm run dev` 仍可启动仅前端的 Vite 服务；未运行 Worker 时公共书库会提示服务未连接。仅前端的生产构建预览：

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

打开[本地预览](http://127.0.0.1:4173/)。两个服务默认仅监听本机，另一台手机无法直接访问此地址。已在浏览器手机尺寸下检查布局，真实 iOS/Android 操作仍需验证。

首次克隆后公共书库为空。登录本地测试账号后，可上传有权分享的 PDF 到本地书库；私人文件请在上传时选择「仅自己可见」。仓库不包含研究论文或翻译任务，旧版本的可选示例不再由当前应用提供入口。


### 通过 Wi-Fi 在手机上预览

构建后运行 `npm run preview -- --host 0.0.0.0 --port 4180 --strictPort`。手机连接同一个 Wi-Fi，访问 `http://电脑的局域网IP:4180`。保持电脑唤醒和预览进程运行。请在可信局域网中使用：`public/` 打包进去的文件（含本地样例）可被能访问此端口的设备读取。这仍是本地预览，不是公网部署。

局域网 HTTP 访问已为 PDF 哈希和笔记标识提供浏览器端兼容处理；剪贴板 API 不可用时尝试浏览器的旧式复制操作，仍可能受浏览器权限限制。数据保存在各自浏览器中，局域网地址与 localhost 的存储独立；真实 iOS/Android 验证仍待完成。

## 双语工作流

导入最终双语 PDF 后即可查看原版。若要使用段落和术语功能，使用 [BabelDOC 适配器](docs/BABELDOC.md) 导出 `.yuejian.json`，与匹配的 PDF 一同导入。为兼容已有预览数据，阅读包标识暂时沿用旧名称。 适配器支持英译中、中译英、嵌套术语表、混合批次目录和早期翻译跟踪文件。本地文献列表可按版本增量导入，更新阅读包时保留已有笔记、书签和进度。

## 数据与隐私

公开上传的 PDF 和阅读包存入 R2（本地开发时模拟），D1 保存书库目录及各账号的阅读记录。公开接口不返回个人笔记或上传者身份。上传前明确确认公开分享，原有本机文件不会自动上传。默认设置 8 GB 的应用文件存储上限，包含上传中的文件和已撤下文件；这不是 Cloudflare 全账号的账单硬上限。

兼容原有 IndexedDB `yuejian-library`：`books` 保留文件与游客记录，`settings` 按账号保存个人记录及待同步修改。切换账号不会混用笔记；当前应用不再提供游客记录合并功能。清理网站数据会丢失缓存及未同步修改，已同步的账号记录可从服务恢复。Markdown 导出仍不是完整文献库备份。

私有示例、截图、生成资源、依赖、构建产物和本地凭据均排除出 Git。**即使被 Git 忽略，`public/` 中的文件仍会被 Vite 复制进构建产物。** `npm run build:cloud` 使用资源白名单生成 `dist-cloud/`，排除所有本地样例；后续部署仍应从干净检出构建并检查产物。详见[安全与数据说明](SECURITY.md)。

## 许可状态

项目原创代码尚未选定许可证，包元数据标记为 `UNLICENSED`。第三方组件保留各自许可证。论文和译文不属于应用代码，本仓库不分发这些材料。

TXT 与私密上传：私密文件、元数据及阅读包经账号权限校验，相同文件的不同账号私密副本使用独立标识；公开上传仍需主动确认。已有文献保持公开，私密缓存不出现在本机文献列表。旧部署需先执行 [数据库增量迁移](docs/CLOUDFLARE.md#txt-与私密上传迁移)。
